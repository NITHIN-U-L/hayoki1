# Photo upload guide

Put your photos in this `images` folder with exactly these names (.jpg).
Missing photos are skipped automatically, so you can start with 1 photo per product.

- `logo.png` : your store logo
- `dutch-oven-1.jpg` to `dutch-oven-5.jpg` : photo 1 is the main picture
- `stoneware-set-1.jpg` to `stoneware-set-5.jpg` : photo 1 is the main picture
- `towel-set-1.jpg` to `towel-set-5.jpg` : photo 1 is the main picture
- `table-lamp-1.jpg` to `table-lamp-5.jpg` : photo 1 is the main picture
- `storage-basket-1.jpg` to `storage-basket-5.jpg` : photo 1 is the main picture
- `french-press-1.jpg` to `french-press-5.jpg` : photo 1 is the main picture
- `linen-duvet-1.jpg` to `linen-duvet-5.jpg` : photo 1 is the main picture
- `soy-candle-1.jpg` to `soy-candle-5.jpg` : photo 1 is the main picture

Customer review photos go in `images/reviews/` (example: `p1-priya-1.jpg`). Use the same file names in `index.html`.

Tip: keep each photo under about 300 KB so the site loads fast on mobile.
